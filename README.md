# 會計資料去敏與 AI 結果還原

目前是小樣本本機網頁：先將識別資料換成代號，AI 整理後再以同批還原檔換回原值。原始檔案保持不變，去敏資料與還原結果另存。

## 開啟範例

下載專案後，用瀏覽器開啟 [會計憑證本機去敏.html](artifacts/deidentification-ai-restore-20261020/accounting-weekly-v1/會計憑證本機去敏.html)，按「用範例試試」。網頁不需安裝套件，不會自動呼叫 AI 或傳送資料。

1. 選擇資料，按「產生去敏資料」。
2. 分別「儲存去敏資料」與「儲存還原檔」。還原檔留在自己電腦，不提供給 AI。
3. 將去敏資料解壓縮，把裡面的資料與操作說明提供給 AI。請 AI 回傳 CSV，保留完整代號與每列的「批次編號」。
4. 選擇當時儲存的還原檔與 AI 結果，按「還原資料」，查看結果後「儲存還原結果」。

AI 可以合併、刪改、新增或重排資料列及欄位；還原依完整代號對應，不依原始列位置。多個對象合併時需保留全部代號。已刪除的資料列不會補回，刪掉的代號或遮蔽文字無法推回原值；不同批次會停止還原。

## 目前內容與範圍

- [現行程式與規則](artifacts/deidentification-ai-restore-20261020/accounting-weekly-v1/)：來源程式、可直接開啟的網頁、3 份合成 CSV，共 30 筆、25 欄。28 筆放入 AI 去敏資料，2 筆私人或不適用資料排除。
- [需求盤點文件](artifacts/customer-intake-guides-20261020/)：逐題引導稿及角色扮演填寫範例。這些是討論參考，不代表實際客戶需求已確認或功能已全部完成。
- 現有匯入功能支援 CSV；尚未實作 Excel 匯入。介面已精簡為選資料、保存兩份檔案、還原三步驟。
- 本庫不收錄真實客戶資料、還原檔、含原值的執行輸出或舊交接壓縮包。原有本機檔案仍保留。

## 修改與驗證

需要 Node.js，使用內建模組，無額外套件。從專案根目錄執行：

```sh
cd artifacts/deidentification-ai-restore-20261020/accounting-weekly-v1
node package.mjs
node test.cjs
node test-restore.cjs
node test-ui.cjs
```

`package.mjs` 只重新打包網頁，不重寫合成原檔。`build.mjs` 是合成資料生成器，會重寫範例；一般介面維護請用 `package.mjs`。

請依上述順序測試：還原測試會產生介面測試需要的本機測試檔。測試輸出存於 `runs/`，不納入版本管理。

2026-10-20 驗證：15 項去敏回歸、19 項還原測試與 8 項介面模擬檢查通過。模擬 AI 合併、刪改等操作後留下 25 筆結果，209 格可正確還原。未呼叫外部 AI，尚未完成實際瀏覽器畫面驗收，也不代表客戶正式驗收。
