# 去敏需求盤點：三個重點引導稿

版本：1.1  
日期：2026-10-20  
用途：沿用已知背景，一輪處理一個重點，由引導者整理答案，最後交付 Markdown 盤點結果。

## 已回答的內容：直接沿用，不重問

以下來自本輪角色扮演的口述回答，尚未核對實際公司檔案。

| 項目 | 已知內容 |
|---|---|
| 收到的資料格式 | Excel、CSV |
| 本次先盤點的格式 | Excel |
| 資料名稱 | 審計資料 |
| 來源與整理方式 | 原始來源不一，由經手人整理成公司統一版本 |
| 本次處理階段 | 整理後的公司統一版本 |
| 希望 AI 協助的工作 | 合併資料、審計與檢查 |
| 尚未盤點 | Excel 的實際欄位、內容、去敏需求及輸出要求；CSV 的細節 |

不再追問資料名稱、來源、整理前後或三項工作的優先順序。先完成這份 Excel 的三個重點，CSV 保留為尚未涵蓋範圍，不自行套用相同規則。

## 引導方式

- 一次只提出下面一個重點問題，等回答後再往下走；不一次展示整份問卷。
- 每次先用一句話整理剛才的答案。對方沒有提供的資訊標為「待確認」。
- 一個重點可以涵蓋多個欄位，不逐欄、逐個背景細節重複開一輪。
- 只有答案有矛盾，或缺口會直接影響去敏決定時，才補一個必要的釐清問題。一般技術細節留待確認。
- 不把我們的合成資料、25 欄或處理規則當成對方現況。
- 只需描述欄名、內容類型與格式，不要求真實姓名、帳號或客戶資料。
- 本次只盤點與試走，不修改網頁、不執行去敏、不把口述需求當成外送授權。

## 重點一：檔案有哪些欄位或內容？

承接已知背景：

> 我們就以你們整理後、統一格式的「審計資料」Excel 為範圍，確認內容、去敏需求與輸出要求。

本輪只問：

> 這份「審計資料」Excel 主要有哪些欄位或內容？可以直接列欄名或用平常的說法描述，不需要提供真實資料。

引導者整理：依對方實際回答列出欄位與內容；若主動提及多個工作表、公式、圖片、備註或隱藏資料，一併記錄。不要求對方逐一回答整份技術檢查清單。沒有提到的項目不能當成不存在，必要時列待確認。

## 重點二：哪些一定要去敏，哪些必須保留？

先顯示依上一輪整理的簡短內容清單，再只問：

> 在這些內容裡，哪些一定要去敏、哪些必須保留，才能完成你們的合併、審計與檢查？不確定的可以一起列為待確認。

引導者整理成三組：

- 需要去敏或只限本機的資訊。
- 為完成工作需要保留的資訊及用途。
- 尚未決定的資訊與疑問。

不預設金額、日期、公司名稱可保留。若同一資訊同時被要求去敏與保留，只釐清影響決定的差異，例如「需要保留真實名稱，還是能辨認同一個客戶就足夠？」不要求對方選程式或演算法。

將對方明確的需求與引導者提出的處理建議分開；尚未確認的代號、遮除或精度調整不能記成已決定。

## 重點三：去敏後要維持什麼格式與對照關係？

承接上一輪已記錄的保留需求，不重問，再只問：

> 去敏後，檔案需要維持哪些格式或對照關係，才方便你們繼續工作和人工檢查？例如原 Excel 排版、欄名與順序，或同一客戶在不同檔案中的對應。

引導者整理：只記錄對方提出的要求，包括工作表、欄列位置、公式、原檔對照、跨檔關聯等。例子只是協助理解，不自動全部列為需求，也不宣稱目前網頁已具備這些能力。

## 三輪後：整理盤點結果

由引導者產出下列 Markdown，不把空白表格交給對方填，也不開始修改網頁。

|---|---|---|---|

## 格式與對照要求

整理對方實際提出的要求，不補入範例假設。

## 引導者建議

只列必要建議，清楚標示尚待對方確認；沒有建議可省略。

## 尚未釐清的事項

整理後讓對方有機會更正。三輪不足以確認所有規則時，交付「初步盤點結果」及缺口，不將訪談無限拆細，也不宣稱完成安全驗收或獲准外送資料。
